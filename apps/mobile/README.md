# AYROVI (تطبيق الهاتف)

تطبيق React Native (Expo) — **المجلد الوحيد** المسموح يحتوي كود التطبيق في هذا المستودع.

| الملف | واش فيه |
|---|---|
| `PLAN.md` | الخطة الكاملة: الميزات، المراحل، المعمارية، واش يلزمنا من الخادم |
| `app/` | الشاشات (expo-router) |
| `src/` | الشبكة، المصادقة، التصميم، اللغة، الحالة |
| `assets/` | الخطوط والشعارات (مصدرها هوية المنتوج) |
| `src/api/` | عميل الـ HTTP، الأخطاء، والمحتوى العام |
| `src/features/` | أقسام الشاشات (hero، شريط التنقّل، الإعلانات) |
| `scripts/gen-tokens.mjs` | يولّد `src/design/tokens.generated.ts` من هوية المنتوج |
| `metro.config.js` | بروكسي تطوير: `/api` و`/media` نحو الخادم المحلي |
| `tests/` | اختبارات التطبيق (مستقلة عن اختبارات الموقع) |

## القواعد (ملزمة)

1. **كل شي تحت `apps/mobile/` = التطبيق.** لا كود تطبيق خارج هذا المجلد.
2. **ممنوع `import` من `client/`** (كود الويب). `shared/` للأنواع فقط.
3. **HTTP فقط** في التعامل مع الخادم — لا منطق تسعير ولا كشف ولا كابتشر هنا.
4. التطبيق يهدر مع الخادم بنفس عقد الـ API متاع الموقع. أي تعديل لازمني في الخادم يكتب في `PLAN.md` §7.
5. CI: مهمة `mobile` مستقلة بـ `paths: apps/mobile/**`.

الاستثناء الوحيد للقاعدة 2: `scripts/gen-tokens.mjs` **يقرا** ملف
`client/src/design/editorial/identity.json` وقت البناء (موش وقت التشغيل) — باش تكون
نفس الهوية في الموقع والتطبيق، بلا نسختين يدوية.

## الهوية

نفس التطبيق، موش تطبيق جديد: الاسم **AYROVI** والمعرّف `app.ayrovi.mobile` (نفس ما كان في
`capacitor.config.ts`)، و`versionCode` يبدا من **7** (القديم كان 6). كي نكمّلو بنفس المعرّف
ونفس مفتاح التوقيع، اللي عندو النسخة القديمة **يترقّى** بلا ما يعاود ينصّب. التفاصيل في `PLAN.md` §1.

Deep link: `ayrovi://` (نفس scheme القديم).

## كيفاش تشغّل

```bash
cd apps/mobile
npm install            # legacy-peer-deps=true مفعّلة في .npmrc

npm run tokens:build   # يولّد التوكنات من الهوية (ضروري قبل أول تشغيل)
npm start              # Expo — امسح رمز QR بتطبيق Expo Go
npm run android        # أو مباشرةً على محاكي/جهاز متصل
npm run web            # معاينة في المتصفح
```

## الفحوص

```bash
npm run tokens:check   # التوكنات مطابقة للهوية؟
npm run typecheck      # TypeScript
npm test               # اختبارات اللغة والهوية الرقمية
```

## الأصل (الشعارات والخطوط)

| الملف | المصدر |
|---|---|
| `assets/fonts/*.ttf` + `*-OFL.txt` | `../../assets/fonts/` (نفس خطوط الموقع) |
| `assets/images/icon.png` | `../../assets/icon.png` (شعار على `#FAFAFA`) |
| `assets/images/adaptive-icon.png` · `splash-icon.png` · `favicon.png` | وُلّدت بـ sharp من `../../client/public/media/logo-ayrovi-512.png` |

الألوان والأبعاد كاملة تجي من `src/design/tokens.generated.ts` — **ما تصلّحش بيدك**، صلّح
الهوية ولا بدّل السكربت.

## تطوير محلي مع الخادم

التطبيق في التطوير **ما عندوش عنوان خادم ثابت**: الطلبات تخرج نسبية
(`/api/public/…`) و**بروكسي Metro** يردّها على الخادم المحلي. المعنى:
نفس البناء يخدم على أي جهاز، وبلا إعداد CORS، وبلا ما تعرف عنوان الشبكة.

```bash
# 1) الخادم (من جذر المستودع)
npm run build && PORT=3000 node dist/server.js

# 2) التطبيق (نافذة أخرى)
cd apps/mobile && npx expo start --web --port 8081
```

البروكسي يوجّه افتراضياً لـ `http://localhost:3000`؛ بدّل بـ `AYROVI_DEV_API`،
وتجاهل الـ `/api` لو كان عنوان مطلقاً متاع نسخة مغلقة أو إنتاج.

في البناء الحقيقي (EAS) نحدّد العنوان صريحاً:

```bash
EXPO_PUBLIC_API_BASE_URL=https://ayrovi.tn eas build --profile preview
```

## الحالة

- **P0 — الشل: منجز.** تنقّل بخمس تابات (تنقلب في العربية)، فرنسي/عربي، ثيم
  فاتح/غامق/تلقائي، خطوط الهوية مدمجة، ختم بناء، CI.
- **P1 — الشبكة والرئيسية: منجز.** عميل HTTP بعقد أخطاء واضح، الرئيسية تعرض
  محتوى الخادم الحقيقي (hero + تنقّل + إعلانات)، حالات تحميل/خطأ/بلا شبكة،
  سحب للتحديث، بروكسي تطوير.
- **P2 — الحساب (الجزء الأوّل): منجز.** الدخول بالـ SMS (OTP) وبالبريد وكلمة السرّ،
  الجلسة في خزنة الجهاز (Keychain/Keystore) وترجع وحدها بعد إغلاق التطبيق، «الخروج»
  يلغي الجلسة في الخادم فعلاً، وشاشة الحساب والطلبات. الخادم: تصريح العميل
  (`x-ayrovi-client`) + `Bearer`، وحدود معدّل بالجلسة قبل الـ IP.
- **P2.2 — بقية الحساب: منجز.** ملف الحساب، العناوين، المفضلة، الإشعارات،
  التفضيلات، الأمان (تبديل كلمة السرّ)، وقائمة الطلبات + تفاصيل الطلب بالتتبّع.
- **P2.3 — كلمة السرّ المنسيّة وصورة الملف والمزوّدون: منجز.** طلب رابط
  الاسترجاع من التطبيق (والخادم يرجّع 202 «مقبول» موش «مُسلَّم»)، صورة الملف
  (multipart، الخادم يعيد الترميز 256×256)، دخول Google/Apple/Facebook بكود
  إزالة يُستلم مرّة وحدة. المفاتيح الحقيقية للمزوّدين **موش موجودة في التطوير**:
  الشاشة ما تعرضش زرّ إلا إذا قال الخادم `enabled`، وتكتب السبب في غير ذلك.
- الخطوة الجاية: **P3 — AYWEBs** (لصق رابط → كابتشر → سعر → سلّة → دفع،
  `PLAN.md` §11)، وبعدها P4 Lens. التفاصيل والمصادر في `PLAN.md` §12.
