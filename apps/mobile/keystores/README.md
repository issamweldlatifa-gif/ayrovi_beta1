# مفتاح التوقيع التجريبي (`debug.p12`)

## هذا **مو**ش سرّ — و**مو**ش مفتاح الإصدار

| | |
|---|---|
| الاسم المستعار | `androiddebugkey` |
| كلمة سرّ الملف والكلمة | `android` (كلمة السرّ العمومية لمفتاح Android التجريبي) |
| يُستعمل في | APK العرض التجريبي (`mobile-android.yml`) وبرك |
| **لا** يُستعمل في | AAB الإنتاج — موقّع بمفتاح صاحب المشروع من أسرار GitHub (`mobile-release-aab.yml`) |

المفتاح التجريبي في أندرويد **مصمّم أصلاً باش يكون غير آمن ومشترك** (وثائق
أندرويد تقولها بالصريح). توقيع APK تجريبي بمفتاح تجريبي = السلوك العادي، موش
تساهل أمني.

## لماذا هو **محفوظ في الريبو** (وهذا مقصود، موش سهو)

من غير مفتاح مثبّت، Gradle يولّد مفتاحاً جديداً على **كل جهاز** ⇒ كل بناء
تخرج بـ**بصمة مختلفة**. و`/.well-known/assetlinks.json` (الملف اللي يأذن
لأندرويد باش يفتح روابطنا في التطبيق) ما ينجم يعلن كان قائمة محدودة من
البصمات.

النتيجة: **«افتح في التطبيق» مستحيل تجربتو على APK تجريبي** — موش لأنّ فيه
علّة، ولكن لأنّ البصمة ما تثبتش.

مفتاح محفوظ ⇒ بصمة **واحدة ثابتة** ⇒ الروابط العميقة تتجرّب فعلاً قبل الإصدار.

## البصمة (SHA-256)

```
8E:20:AB:BB:68:D8:AE:88:21:C6:08:A5:77:C7:DB:CD:97:80:66:B2:86:7C:D5:BF:84:7B:3C:2E:5D:A1:52:53
```

تتحطّ في خدمة الـBeta هكذا:

```
ANDROID_APP_LINK_SHA256 = 8E:20:…:52:53
```

(وعند الإصدار الحقيقي: تزيد بصمة مفتاح الإصدار **و**بصمة إعادة توقيع Google
Play — Google تعيد توقيع الحزمة بمفتاحها، والبصمتين لازم يكونو معلنين.)

## كيفاش يتولّد (لو احتجنا نبدّلو)

```bash
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 10950 -nodes \
  -subj "/C=US/O=Android/CN=Android Debug"
openssl pkcs12 -export -in cert.pem -inkey key.pem -out debug.p12 -name androiddebugkey \
  -passout pass:android -certpbe PBE-SHA1-3DES -keypbe PBE-SHA1-3DES -macalg SHA1
```

والبصمة:

```bash
openssl x509 -in cert.pem -noout -fingerprint -sha256
```

⚠️ تبديل هذا الملف يبدّل البصمة ⇒ الروابط العميقة تنقطع حتى يتحدّث
`ANDROID_APP_LINK_SHA256` في الخادم.

## ⚠️ المتغيّر الثاني (لازم بجوج)

البصمة وحدها تطلع البيان، بس **لحزمة الإصدار وحدها** (`app.ayrovi.mobile`).
الـAPK التجريبي حزمتو `app.ayrovi.mobile.demo` وما تتغطّاش بالافتراضي ⇒ باش
تجرّب «افتح في التطبيق» بالـAPK التجريبي، **زيد المتغيّر الثاني**:

```
ANDROID_APP_LINK_SHA256 = 8E:20:…:52:53
ANDROID_APP_LINK_PACKAGES = app.ayrovi.mobile,app.ayrovi.mobile.demo
```

والفحص الآلي يقولها (حالة `production-seule` كان ناقص).
