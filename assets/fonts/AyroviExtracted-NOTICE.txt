AYROVI EXTRACTED SANS — FONT DERIVATIVE NOTICE

This font is derived from the verified variable WOFF2 that was observed being served by Zalando's public website and used as the source for the project's glyph-outline extraction. The original WOFF2 SHA-256 is:
ba6fc11db691debbd271564b194e37d96fab6d3d58c96574c58ce15696196a8f

The derived family is renamed “Ayrovi Extracted Sans” to distinguish this project build from the reserved upstream family name. The web font retains the source variable outlines and axes. The mobile/PDF TTFs are static instances at weight 400, 600 and 700, width 100, generated from that same WOFF2. Export rounds fractional outline coordinates to integer font units; the build validator enforces a maximum outline-coordinate difference of 1 font unit and exact advance-width parity.
