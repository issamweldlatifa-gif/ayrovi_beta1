# تباين مدخل Clean وحجم زر الحركة — تطبيق الهاتف فقط

طلب المالك إبراز بياض مدخل الكتابة وضبط حجم الدائرة البرتقالية مقارنة بمرجع ChatGPT المرفق من هاتفه. المدخل كان بالفعل يستعمل #FFFFFF، لكن الخلفية المحيطة كانت بيضاء أيضًا؛ لذلك التغيير تباين موضعي، لا ادعاء تصحيح لون أبيض غير موجود.

- مدخل النص وحاويته #FFFFFF صراحة، مع نص أسود، دون underline Android افتراضي.
- خلفية Clean المحيطة/العنوان #F7F7F7، دون تغيير لون فقاعات الرسائل أو هوية المتجر أو palette المشتركة مع الويب.
- حواف الحاوية 28dp؛ حجم الرسم البرتقالي 32×32dp مع viewBox يحيط بالدائرة كاملة، بدل SVG 44dp ذي هوامش داخلية. يبقى اللون #FF6800، وحالات wave/send/busy/recording كما هي.
- مساحة الضغط 44×44dp مستقلة عن حجم الرسم. لا تغيير وظائف إرسال/إيقاف/تسجيل أو مرفقات أو رفع لوحة المفاتيح.
- القيم الجديدة tokens مخصصة لـClean في tokens.mobile وليست defaults عامة. لا تعديل client/ أو shared/cleanAppearance.json.

التحقق: 4 مجموعات UI / 19 اختبارًا ناجحًا، تشمل الإرسال والتسجيل والكاميرا والكيبورد واختبار اللون والحجم؛ واختبارا design-system/clean-keyboard: 29 اختبارًا ناجحًا. فحص أنواع الهاتف وتصدير Android bundle نجحا. تحذيرات act/handles المعروفة في harness بقيت؛ استعملت UI suite --forceExit. لا مطابقة pixels فعلية على الهاتف أو بناء/تثبيت APK في هذه الدفعة؛ 32dp اختيار مطابق تقريبًا لحجم المرجع الظاهر، وليس قياسًا مضمونًا عبر كل كثافات الشاشات. يلزم نسخة تطبيق تحتوي التحديث لرؤية الفرق.
