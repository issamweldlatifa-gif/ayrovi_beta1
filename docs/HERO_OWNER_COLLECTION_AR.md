# تحديث Hero في التطبيق

- ست فئات بالترتيب: Mode homme، Mode femme، Mode bébé، Mode électrique، Mode maison، Mode sport.
- استبدال الصور الأربع القديمة المضمّنة وإضافة صورتَي الطفل والمنزل. الصور الجديدة من المرفقات، والتقنية من Tech Essentials.jpg. لم تُضف صورة العناية ولا بديل التقنية الأزرق.
- تركيب 5:8 مع الاحتفاظ بكامل الصورة ومساحة علوية للنص، عناوين sans-serif عريضة من عائلة الخط الموجودة، أسود على الفاتح وأبيض على التقنية الداكنة، ووصف فرنسي وعربي.
- لم يتغير موقع الويب ولا التخزين ولا مخطط قاعدة البيانات. لم تُحذف صور CMS أو بيانات الإدارة.
- المجموعة مضمّنة في APK التجريبي عند EXPO_PUBLIC_HERO_DEMO=1 فقط. منشورات CMS تبقى أعلى أولوية. هذا ليس استبدالًا منشورًا على السيرفر، ولا ضمانًا أن جهازًا حاليًا يعرض المجموعة الجديدة. يلزم APK جديد؛ إذا كانت هناك منشورات إدارة نشطة يجب تحديثها أو إلغاء نشرها عبر الإدارة بعد مراجعة المحتوى.
- روابط الكروت تفتح الكتالوج العام الموجود؛ لا ندّعي تطبيق فلتر فئة غير مربوط ببيانات فعلية.

التحقق: فحص TypeScript، 87 اختبار منطق/تصميم، 15 اختبار واجهة للكاروسال (تشمل أسماء الفئات والصور المحلية ولوني النص). لا توجد معاينة مثبتة على جهاز حقيقي أو APK مبني ومثبّت ضمن هذا التحديث.
