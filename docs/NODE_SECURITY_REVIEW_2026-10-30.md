# Node and dependency security review — 2026-10-30

The [Node.js October security release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) fixes several high-severity issues including CVE-2026-111497 (Brotli), DNS and TLS issues. The fixed Node 22 release is 22.23.4. The repository previously configured Render to use 22.22.0 and several workflows used the unsupported Node 20 line. The sandbox initially reported 22.22.3; the validation below used an independently installed 22.23.4, without modifying the sandbox's system Node.

Render's blueprint, CI workflows and `.nvmrc` now specify 22.23.4. A successful deployment and the actual Node version of every running Render instance must still be checked in Render; repository configuration alone does not prove the running service has changed. Rebuild and restart other deployments or images that embed Node separately. The esbuild `node20` target is a JavaScript output compatibility target, not a runtime selection.

Both lockfiles were refreshed using `npm audit fix --package-lock-only`, without `--force`, and installed cleanly with `npm ci`. As of this review, the root npm audit reports zero advisories. The mobile audit reports 16 affected packages (6 high, 10 low), including dependency chains from Expo Router's query-string/decode-uri-component, Expo CLI's Zod 3, and deepmerge via Expo and Jest. Counts are affected package entries, not 16 distinct CVEs. npm proposes a breaking SDK/router upgrade or an Expo downgrade; neither is a safe automated fix. A forced override of decode-uri-component would replace a CommonJS dependency with an ESM module, and a Zod 4 override would cross a major API boundary. Investigate upstream compatible fixes and validate any SDK upgrade and URL handling on devices. npm audit results are time-dependent and do not constitute a complete security assessment.

Local validation on Node 22.23.4: root typecheck, production build, design checks and 251 Vitest files passed (3,230 tests, 17 skipped); mobile typecheck, token check, 105 Vitest files (1,103 tests) and 32 Jest suites (165 tests) passed. Jest emitted existing React act warnings and reported open asynchronous handles; these require separate investigation. The earlier AYWEBs image resize invalidated a source assertion, which was updated to the actual new dimensions. This review does not verify live merchant behavior or application security in full.
