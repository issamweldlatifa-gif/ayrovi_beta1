# دفعة فصل قراءة Reels والمنشورات العامة

## التغيير المنفذ

- نُقل SQL المكرر من مساري `/api/public/social/reels` و`/api/public/social/publications` إلى `src/magazine/publicSocialReads.ts`.
- الوحدة تستقبل اعتماد قراءة `all/get` فقط ووقتًا صريحًا للاختبار، ولا تنشئ اتصال قاعدة أو تنفذ كتابة.
- أسماء الجداول والإسقاطات تأتي من مصدرين ثابتين، لا من مدخلات المستخدم. قيم الوقت والمؤشر والمعرّف وحد القائمة تمر كمعاملات SQL.
- توحّد الوحدة التصفية المنشورة والمرساة ومؤشر الاستكمال وقراءة العنصر الإضافي. يعاد قص العنصر الإضافي قبل تجهيز رد المستخدم.
- عقد الصفحة وترميز المؤشر في `src/magazine/socialPagination.ts`، مستقلان عن HTTP. محلل query في `src/public/socialPaging.ts` ما زال مسؤولًا عن التحقق من مدخلات HTTP؛ احتُفظ بإعادة تصدير الأنواع والمُرمّز للتوافق مع الاستيرادات السابقة.
- مسارات HTTP ما زالت مسؤولة عن الرد 400 للصفحة غير الصالحة، وأغلفة JSON، وتحويل المنتج المرتبط وإرفاق قائمة المنتجات عبر الوظائف القائمة؛ لا نسخة ثانية لقواعد البيع أو التسعير.

لا جداول أو أعمدة أو فهارس جديدة، ولا تعديل بيانات أو إعدادات استضافة. SQL ما زال خاصًا بـSQLite؛ هذه حدود تنظيمية تساعد التكييف لاحقًا وليست دليل جاهزية PostgreSQL أو فصل خدمة مستقلة.

## السلوك المحفوظ والأدلة

اختبارات المصدرين تقارن الإسقاط الكامل بالاستعلام السابق وتتحقق من المرور عبر الصفحات إلى نفس النتيجة، بما فيها تساوي التواريخ. تشمل حد النشر الزمني بالضبط، المسودات والمستقبل، مرساة موجودة وأخرى غير متاحة، حذف المرساة قبل متابعة المؤشر، وردود فارغة دون مؤشر وهمي. تشمل أيضًا عدادات views/likes الفعلية في بيانات اصطناعية، ومنتجًا مرتبطًا مع سعره، وإخفاء أعمدة `lp_*` من HTTP، والحفاظ على رد المصفوفة للعميل القديم ورد items/nextCursor للصفحات.

أُعيدت اختبارات المحتوى القابل للتسوق والمنتجات المتعددة والتفاعلات والكتالوج والسلة وبقاء الإعدادات ومراجعة العلاقات.

- 12 ملف خادم، **129 اختبارًا ناجحًا**.
- اختبار API social للتطبيق الأصلي: **13 اختبارًا ناجحًا**.
- TypeScript للموقع والخادم وبناء الموقع والخادم: ناجحة.
- لم تُشغّل مجموعة الخادم الكاملة أو جميع اختبارات واجهة التطبيق؛ لا تغييرات واجهة في هذه الدفعة.
- لا قياس سرعة جديد ولا ادعاء تحسن FPS أو production latency. مسار الرد القديم غير المقسّم لا يزال يحمل قائمته الكاملة للتوافق؛ لم يُحل خطر نموّه بإخفائه خلف طبقة قراءة.

## ما بقي

بقية قراءة وكتابة المحتوى، ومنها publication-feed وتفضيلات المستخدم والتفاعلات، ليست كلها منفصلة عن HTTP بعد. يلزم فصلها على دفعات مع اختبارات المصادقة والملكية والمعاملات، لا دمجها في مستودع عام واحد. كذلك لم تُنجز مراجعة كل مرشحي فهارس FK أو تفكيك ملف database.ts.

```bash
npx vitest run tests/public-social-reads.test.ts tests/social-paging.test.ts tests/social.test.ts tests/shoppable-content.test.ts tests/content-products.test.ts
```
