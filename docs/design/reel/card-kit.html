Ce que ce fichier n'est pas : il n'écrit rien en base et n'appelle aucun endpoint. Il montre la carte telle qu'elle doit sortir du back-office, à la taille du réel, pour trancher maintenant plutôt que dans l'APK.
Où elle doit vivre dans le code : la fiche produit est client/src/admin/CataloguePages.tsx (Catalogue), pas src/crm/ — le CRM de ce dépôt gère les tiers et les tickets. L'aperçu s'ajoute à côté du formulaire, alimenté par le brouillon (draft) avant enregistrement. La carte côté application est apps/mobile/src/features/shopping/LinkedProductCard.tsx ; elle garde son rôle (ouvrir /product/[id]) et prend les cotes de card.css.
