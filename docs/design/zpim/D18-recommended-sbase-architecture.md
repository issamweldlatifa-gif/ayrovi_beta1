## Roadmap المرتب (يحفظ ترتيب العمل المتفق عليه — ملاحظة المالك)

1. **الأولوية غير القابلة للنقاش:** استكمال Commerce Core P1 (مراجعة trio v2.5+D4 → T1 → Approval v1.0) — **ZPIM لا تؤخره**.
2. **بعد الاعتماد:** P1 من D14 (Raw Store، Shape detection، Translation+معجم، trust، quantityPrices، Cache، مرآة صور) — كلها داخل حدود D16.
3. **بعد بنش P2 وأرقام الحجم (D17):** مصدر ثانٍ + failover + كتالوج SEO + بحث صورة + قرار Custom-scrapping إن لزم.
4. فجوة born-AWAITING_DEPOSIT تبقى إصلاحاً **بعد** Approval (قاعدة: لا برمجة P1 قبل مراجعة، لا migrations قبل المراجعة النهائية).

## Checklist مراجعة المالك (قبل أي تنفيذ)

1. اعتماد D11 الشواهد والحُكم (Confirmed/Probable/Unknown).
2. اعتماد خيارات D12 وعدم فتح أي إنفاق.
3. اعتماد عقد `SbaseItem v2` (الإضافات الخمس).
4. اعتماد TTL المقترحة (تفاصيل 7d / توفر-عند-القراءة 24h / خام 60d / بحث بلا كاش).
5. اعتماد خيار «عرض مورّد مجهول» أو إبقاء الرابط ظاهراً (قرار منتج).
6. اعتماد سقف التكلفة اليومي وقيمته الابتدائية.
7. اعتماد حدود D16 كما هي بلا استثناءات.
8. تأكيد أن P1-ZPIM موازٍ لا معطِّل لـCommerce Core.
9. اعتماد بنش Yiwugo كخطوة P2 (بلا إنفاق قبل توقيعه).
10. توقيع T1 على الحزمة ثم Approval v1.0 — عندها فقط يبدأ أي كود.
