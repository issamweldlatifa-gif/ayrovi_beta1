## 3 · جدول التبعيات الحقيقية (من الاستيراد في الكود)

| المنظومة | تعتمد فعلياً على | ملاحظة الحارس |
|---|---|---|
| Z Lens | تحليل روابط AYWEBS (`analyzeAyWebsUrl`) + SerpApi (بصري فقط) | اتجاه واحد؛ لا عكس |
| AYWEBS | BrightData (جلب) + خدمة الثقة السعرية (إنفاذ cartPriceTrust) + Commerce Core (إضافة سلة) | محرك استخراجها الداخلي لا يُستورد من أحد |
| S BASE | Apify-1688 + محرك التسعير + Commerce Core (عقد المتغيرات) | لا يعتمد على Z Lens ولا AYWEBS إطلاقاً |
| Commerce Social | الكتالوج المحلي + Commerce Core | **لا يستدعي أي مسار اكتساب خارجي** — منتجاته كلها كتالوج محلي (مثبت في `cart.ts`) |
| Commerce Core | لا يعتمد على أي منظومة اكتساب (مزوّد الخدمة) | حد D16 |
| ZPIC (مستقبلاً) | مزوّدوها فقط (Apify connector بعد P1-B + AI Core adapter لاحقاً) | لا يستورد من aywebs/zayrovix (§8) — يُستهلك ولا يستهلك |

**قواعد منع الدورات (تلخيص §8 من D20):** المستهلك→ZPIC→مزوّد، بلا سهم عكسي؛ لا استيراد متبادل بين منظومتين عبر ZPIC؛ مزوّد كل منظومة يبقى داخلها؛ فحص imports آلي في كل PR + git diff نصي صفر على الداخليات المحمية.

## 4 · ما تضيفه هذه الخريطة على سابقاتها

- **Commerce Social دخل الخريطة رسمياً** لأول مرة في حزمة ZPIC (كان خارج نطاق D19 الأصلي لأنه ليس مسار اكتساب — يستهلك الكتالوج المحلي) بفئتي بيانات #5 و#4.
- **فصل فئة #7 عن #8**: الثقة السعرية (توقيع/تحقق — Commerce Core) ≠ التسعير التجاري وFX (محرك التسعير) — حتى لا تُقرأ خدمة التوكن المستقبلية أنها تقرر الأسعار.
- **الهوية (#9) والخام (#11) صراحة**: الأولى خارج نطاق ZPIC نهائياً، والثانية «لا مالك اليوم» — أكبر فضول مسؤوليات محتمل، وأُغلق بمسؤولية ZPIC المعلنة في D20 §5.
