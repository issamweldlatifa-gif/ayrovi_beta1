# دليل النظام التحريري

> أحدث دفعة: [اكتمال سجل SONIM وصدق حالة المنتج](SONIM_HISTORY_REVIEW_AR.md)، وتسبقها [إجراءات SONIM والنوافذ المتداخلة](SONIM_ACTIONS_REVIEW_AR.md) و[مراجعة التعميم والوظائف](FEATURES_CONTENT_REVIEW_AR.md). تقارير الأساس والدفعة 02 سجلات تاريخية، وليست وصفًا للحالة الحالية.

## أين المصدر؟
- `client/src/design/editorial/identity.json`: الألوان الدلالية النهارية/الداكنة، هندسة المكونات، حد مساحة البرتقالي، الخطوط مع checksums وتراخيصها.
- `glyphs.json`: 96 رسمًا تحريريًا مطابقًا لجميع مفاهيم الأيقونات المسجلة حاليًا؛ اتجاه الحركة جزء من التعريف.
- `Icon.tsx`: SVG آمن من أشكال محلية ثابتة، عنوان قابل للوصول ومعرف فريد، عدم قلب الرموز المادية في RTL.
- `primitives.css`: قواعد ذات نطاق صريح؛ للاستخدام مع المكونات المشتركة الحالية عند ترحيل الشاشات، وليس مجموعة Buttons/Fields مكررة.
- `tokens.generated.css`: ملف مولد. تسجيل الخطوط محليًا مفعّل عبر index.css؛ لا تُحمّل الملفات في المتصفح إلا عندما يستخدم عنصر عائلة الخط.
- `client/public/fonts/editorial/`: WOFF2 + OFL. أصلحنا قاعدة gitignore لتجاهل ناتج `/public/` الجذري فقط، لا أصول `client/public/` المصدرية.

## أوامر قابلة للتكرار
```sh
npm ci
npm run design:inventory  # جرد AST متكرر؛ يُحدّث بعد تعديل واجهة العميل
npm run design:build      # CSS + اللوحة من نفس المصادر، دون شبكة
npm run design:check      # يفشل إن انفصلت الملفات المولدة أو الجرد عن المصدر
npm run typecheck
npm run build            # اختبارات HTTP تحتاج صفحة SPA المبنية
npm test
npx playwright install --with-deps chromium firefox
npm run design:browser
npm run verify:editorial-customer
npm run verify:editorial-states
npm run verify:sonim-actions
npm run verify:sonim-history
npm run verify:editorial-account
```

اللوحة `AYROVI-editorial-system.html` مستقلة وتحتوي الخطوط والشعار ولا تطلب موارد خارجية. يمكن تغيير اللغة والوضع، والبحث عن الأيقونات، واختبار مثال تفاعلي معلن بوضوح بأنه ليس شراءً.

## واجهة الاستخدام
```tsx
import { EditorialIcon } from '../../design/editorial';

// أيقونة زخرفية داخل زر يحمل الاسم؛ مساحة الزر منفصلة عن مقاس الرسم.
<button type="button" className="ay-e-button" aria-label="البحث">
  <EditorialIcon name="Search" size={24} />
</button>

// أيقونة مستقلة مسماة؛ الرجوع فقط يتبع اتجاه القراءة.
<EditorialIcon name="Back" title="رجوع" direction="rtl" />
```

CSS الخاص بهوية العميل يتطلب `data-ay-design="editorial"` داخل `CustomerIdentity`؛ محوّل `customerTheme` يربط المكونات الحالية بالهوية دون تغيير إعدادات CMS أو جذر المستند. **عائلة الأيقونات لا تعتمد على هذا السياق:** جميع استدعاءات `QatafoIcons` تستخدم الرسوم التحريرية، بما فيها الإدارة والتنقّل. لا عائلة قديمة أو استثناء للتنقّل.

## عقود لا يجوز كسرها
- مصدر هندسي واحد: `glyphs.json` → `Icon.tsx` → طبقة الأسماء المتوافقة. عدد المفاهيم 96، والأسماء المتوافقة 99؛ تشمل Play وGrip وSonim وVision.
- الشبكة 24، سماكة 1.3، square/miter. لا تغيير سماكة أو نهايات الرسم من الشاشة. يسمح بالملء الدلالي `currentColor` للحالة المختارة.
- `BrandIcon.tsx` وحده يستورد علامات الجهات الأصلية من مكتبة خارجية. شعارات الدفع الأصلية أصول صور؛ التحويل البنكي العام يستخدم الرسم التحريري، لا صورة شعار وهمي.
- الاستثناءات في `icon-exceptions.json` رسوم بيانات/علامة، وليست عائلة UI ثانية. فحص المصدر يشمل العميل والإدارة.
- تثبيت الشعار وترتيب التنقّل وسلوكه لا يعني تثبيت أيقوناته أو خطه القديم.
- أخطاء الشبكة ليست نتائج فارغة أو نجاحًا: شروط التجارة مؤكدة من الخادم، والتعليقات/الإعجابات لا تُحفظ وهميًا في التخزين المحلي.
- يبقى إنشاء طلب غير مدفوع متاحًا **بعد** تحميل سياسة صحيحة تؤكد عدم ضبط بوابة؛ تعذر تحميل السياسة ليس الحالة نفسها.

## حالة العمل
تم تعميم واجهة الأيقونات وتصحيح الصوت وLens ونتائج المنتجات والتعليقات والسلة والدفع ضمن نطاق الاختبارات الموضح في التقرير الحالي. المراجعة اليدوية لكل شاشة إدارية وكل جهاز/مزود خارجي ليست مكتملة؛ اجتياز الجرد والاختبارات ليس ضمانًا بخلو الموقع من كل الأخطاء. إعدادات البريد وهوية Google المؤجّلة لم تتغير.

رموز SONIM وVision وLens ليست استثناءات علامات تجارية؛ الحركة تستخدم الرسم نفسه. لا يجوز إخفاء الكلمات أو التحذيرات لتثبيت ارتفاع بطاقة؛ راجع عقد المحتوى في التقرير الحالي.
