# SONIM — إجراءات الرسائل والنوافذ المتداخلة

## العيوب المثبتة وما تغيّر

| الموضع | العيب السابق | المعالجة |
|---|---|---|
| النسخ | نسخ النص الخام، بما فيه `[[OPEN_LENS]]`، وإشعار فرنسي فقط | سياسة مشتركة تصدّر النص المعروض كاملًا؛ إشعارات عربية/فرنسية، وتفريق النص الفارغ وعدم الدعم والفشل |
| المشاركة | تجاهل جميع الأخطاء باعتبارها إلغاءً | تمييز الإلغاء والرفض والفشل والنجاح؛ النسخ البديل فقط عند غياب Web Share، مع التصريح بأنه نسخ لا مشاركة |
| تكرار الإجراء | إمكان إرسال الإجراء أكثر من مرة قبل انتهاء الوعد | حارس فوري وحالة انشغال؛ تجاهل نتائج المكوّن القديم بعد استبداله أو إزالته |
| القراءة | استدعاء عالمي مباشر بلا إيقاف أو ملكية لدورة التشغيل | قارئ واحد لكل عرض محادثة يستخدم `VoiceOutput`؛ بدء/إيقاف/تبديل، إلغاء عند تغيير المحادثة وإغلاقها، وإظهار عدم الدعم والخطأ |
| اكتمال النص المقروء | تنظيف `VoiceOutput` العام قد يحذف روابط أو محتوى بين أقواس | خيار صريح للحفاظ على النص في قارئ الرسائل؛ لا يحذف سوى الأمر الداخلي بواسطة السياسة المشتركة، ولا يغيّر التنظيف الافتراضي للوضع الصوتي |
| حقيقة حالة الصوت | إعلان التشغيل قبل حدث بدء المحرك، ومستوى صوت اصطناعي في Web Speech | انتظار `onstart` الفعلي؛ لا عرض قياس مختلق عندما لا يتيح المحرك عينات صوتية. قياس صوت الخادم يبقى عبر المحلل الحقيقي |
| التركيز | النوافذ بلا حجز تركيز، والجذر يستعيد التركيز عند كل تبديل طبقة | إعادة استخدام `useDialogFocus` للجذر والنوافذ، وخلفية `inert`، وإزالة الاستعادة المجدولة التي كانت تسحب التركيز من النافذة الفرعية |
| التقييم | تأكيد متفائل قد يرتد إلى حالة قديمة؛ نتيجة متأخرة قد تغلق نافذة أخرى | قبول طلب واحد لكل رسالة في هذا العرض، وإظهار الانشغال، واعتماد النجاح المؤكد. حفظ التعليق مرتبط بالمحادثة **وبنسخة طبقة التنقل نفسها**، لا بمعرّف الرسالة وحده |
| الهاتف والهوية | نافذة تقييم مستديرة، نصوص تاريخ مقتطعة، مفتاح ذو مؤشر أكبر من مساره | استخدام رموز الشكل المربّع المشتركة، عناوين ملتفة كاملة، دور `switch` وحالة مقروءة، ومؤشر داخل المسار |
| التكبير | تجاوز أفقي مثبت عند 320px و200% | إعادة تدفق عنوان النموذج وأزرار التقييم، وحد ارتفاع مع تمرير داخلي، وإمكانية الوصول إلى زر الإرسال دون قصه |

الرد الذي يحتوي بطاقات بلا نص لا يُنسخ أو يُشارك أو يُقرأ كأنه نص موجود. تظهر هذه الحدود بوضوح؛ لم تُحوّل بيانات الطلبات أو المنتجات تلقائيًا إلى حمولة مشاركة جديدة.

## البنية

- `messageActions.ts`: سياسة إخراج النص ونتائج الإجراءات وتسمياتها الثنائية.
- `AssistantMessageActions.tsx`: صف إجراءات مستقل، حالات الانشغال والإتاحة والإعلانات، مع نفس عائلة الأيقونات المعتمدة.
- `useMessageReader.ts`: ملكية الصوت وإبطال النتائج المتأخرة وإيقاف الموارد.
- `VoiceOutput.ts`: تنفيذ الصوت المشترك، لا محرك ثانٍ موازٍ لقارئ الرسائل.
- `AiAssistantDrawer.tsx`: يبقى مالك المحادثة والتقييم والتنقل. لم تتغير وجهات التنقل أو واجهات الخادم أو الشعار.
- نوافذ المرفقات والتقييم والقائمة تستخدم عقد التركيز الموجود بدل نسخ آلية جديدة لكل نافذة.

الاختبارات الجديدة تستخدم المكوّن الفعلي `AiAssistantDrawer` داخل مزوّد التنقل الفعلي، بالعربية والفرنسية عند عرضي 320 و390px. تشمل النقر المكرر، حالات المشاركة، القراءة قبل البدء وبعده، التبديل والإيقاف والأحداث المتأخرة، خروج التركيز وعودته، تعطل إرسال التقييم، إغلاق نافذة أثناء الإرسال وإعادة فتح الرسالة نفسها، والتكبير إلى 200% لحجم خط الجذر.

واجهات المشاركة والحافظة والصوت وكتابة التقييم **بدائل اختبار مضبوطة** في هذه الحزمة؛ ليست إثباتًا أن جهازًا فعليًا نطق الصوت أو فتح قائمة المشاركة الأصلية. فحوص الحساب الأخرى تعمل مع API وSQLite محليين معزولين. لم تُجرَ معاملات حقيقية أو اتصالات بمزوّد دفع أو بريد.

### إخفاقات كُشفت ولم تُتجاهل

- بيئة العمل الجديدة افتقدت المتصفحات ومكتباتها؛ ثُبّتت قبل تنفيذ الاختبارات.
- فشل فحص 200% أولًا: عرض داخلي 486px مقابل 272px متاحين في نموذج التقييم. أُصلح المكوّن ثم أعيد الفحص دون تخفيف شرط منع التجاوز. وأضيف احترام تقليل الحركة للنوافذ.
- فحص قديم كان يبحث عن «الوضع الداكن» بدور `button`. بعد تصحيح دلالته إلى `switch` حُدّث المحدد، وأعيدت المجموعة؛ لم يُحذف التحقق من تبديل الوضع.

## ما لم يُنجز بهذه الدفعة

هذه ليست شهادة أمن شاملة ولا إعلانًا بإكمال جميع الشاشات. يلزم استمرار مراجعة حفظ/استعادة سجل المحادثة وبيانات البطاقات، وبقية نوافذ التطبيق وحالات الشبكة، والاختبار على أجهزة فعلية وقارئات شاشة ومحركات صوت أصلية. ضمان ترتيب التقييم بين تبويبات أو أجهزة متعددة ليس من ضمانات الحارس المحلي.

لم تتغير إعدادات البريد أو Google المؤجلة، ولا خدمة Vision غير المفعّلة، ولا الشعار أو سياسة قبول المنتجات. آخر إصدار منشور متحقق منه يظل `d9d5d30` حتى يثبت نجاح دفع ونشر أحدث؛ نتائج هذا التقرير محلية فقط.
