# SONIM — تشغيل الردود الصوتية، الإلغاء وصدق الإعدادات

## حالة هذه الدفعة

هذه مراجعة محلية تالية لدفعة ملكية المرفقات والتسجيل `50d0d59`. تتناول **إخراج الصوت**: صوت الخادم، وصوت الجهاز البديل، والقراءة المباشرة للرسائل، وعرض إعدادات الصوت. نتائج الاختبارات أدناه لا تعني أن التعديل دُفع إلى GitHub أو نُشر على Render؛ تبقى المصادقة والنشر والتحقق البعيد مراحل مستقلة.

لم تتغير عائلة أيقونات SONIM وVision وLens أو الشعار أو التنقل، ولا الخادم والتسعير والبريد وهوية Google المؤجلة.

## إثبات العيوب قبل الإصلاح

أضيفت 14 حالة انحدار إلى `tests/voice-output.test.ts` ثم شُغّلت على التنفيذ السابق قبل تغييره: **نجحت الاختبارات القديمة الـ11 وفشلت الحالات الجديدة الـ14**. السجل المنظم في `SONIM_PLAYBACK_BASELINE.json`؛ هذه إخفاقات متوقعة للنسخة السابقة، وليست نتيجة فحص الإصدار الجديد.

شملت الحالات:
- اعتبار عبارة المتصفح قيد الانتظار «قيد التشغيل» قبل وصول حدث البدء.
- تكرار إشعار البدء وقبول خطأ متأخر بعد انتهاء القراءة.
- استمرار خطوات قياس المستوى بعد إلغاء التشغيل من داخل استدعاء البدء.
- حذف الأسعار بين الأقواس المعقوفة والروابط والشرطة السفلية والفقرات عند تجهيز كلام الوضع الصوتي.
- بقاء وعد التشغيل معلقًا إذا تجاهل النقل الإلغاء أو تأخر فك الصوت؛ وعدم كفاية مهلة الطلب لإنهاء انتظار فك الترميز.
- تغيير إعدادات العملية أثناء انتقالها من الخادم إلى صوت الجهاز، وإعلان خطأ/انتقال قبل نجاح البديل فعليًا.
- أخطاء نهائية غير مترجمة أو إشعارات انتهاء ناقصة، واعتبار كلمة `female` مطابقة للنمط `male`.
- اختلاف نوع الصوت المحلي عن إعداد preset عند تمرير إعداد جزئي.
- اعتبار انتهاء المهلة إلغاءً عاديًا إذا أرسل المحرك حدث إلغاء متزامنًا، وقطع القراءة الطويلة عند سقف عشر دقائق ثابت.

## ما تغير

### ملكية الانتظار والتشغيل

- `media/awaitOwned.ts` تجريد مشترك للصور والصوت: ينهي انتظار المستهلك عند الإلغاء حتى لو لم تستجب واجهة المتصفح أو وسيلة النقل، ويستهلك الرفض المتأخر. يستطيع أيضًا تحرير نتيجة أصلية تصل متأخرة، مثل `ImageBitmap`.
- طبّق `VoiceOutput` هذا العقد على طلب الصوت وقراءة جسم الاستجابة واستئناف `AudioContext` وفك الصوت. تُفحص ملكية العملية قبل استعمال النتيجة؛ الإلغاء لا ينشئ صوتًا لاحقًا أو ينتقل سرًا إلى بديل.
- حالة الانشغال منفصلة عن حالة التشغيل. يبدأ صوت الجهاز عند `onstart` الحقيقي؛ ولا يعامل وجود utterance في الطابور على أنه كلام مسموع. صوت Web Audio لا يبدأ إلا مع سياق صالح قيد التشغيل ونجاح `source.start`.
- استدعاء انتهاء واحد لكل عملية كاملة، لا استدعاء لكل محاولة نقل. تعذر الخادم قبل البدء يسمح ببديل محلي؛ أما تعذر إنهاء صوت بدأ بالفعل فيُعلن كفشل **دون إعادة قراءة الرد كله**.
- تُزال معالجات العبارة عند نهايتها أو إلغائها، وتُحمى المعالجات التي قد تكون حُجزت سابقًا في طابور الأحداث. لا يستطيع إطار قياس قديم محو مرجع إطار العملية الأحدث.

### مهل صادقة، لا نجاح مفترض

- مهلة تجهيز صوت الخادم **22 ثانية** تشمل الاستجابة وجسمها والاستئناف وفك الترميز.
- للعبارة المحلية التي لا تبدأ مهلة **15 ثانية**. بعد بدء الكلام تحسب مهلة احتياطية بحسب طول النص والسرعة المختارة، دون سقف العشر دقائق القديم.
- إذا لم يصل حدث انتهاء مصدر Web Audio، توجد مهلة تعتمد مدة التسجيل المفكوك مع عشر ثوانٍ إضافية. انتهاء المهلة نتيجة `unavailable`، وليس اكتمالًا ناجحًا أو إلغاءً طوعيًا.
- إشعار الخطأ النهائي عربي أو فرنسي ويصدر بعد استنفاد المسار المتاح، لا لمجرد فشل محاولة الخادم إذا نجح البديل. متحكم المحادثة لا يكرر الإشعار نفسه.

### المحتوى والإعدادات

- التحضير الافتراضي للصوت يستخدم `cleanAssistantText` المشترك؛ يحتفظ بالأسعار والروابط والمعرفات والفقرات، ويزيل أمر الواجهة المعروف `[[OPEN_LENS]]` فقط مع الفراغات الطرفية. الرد الذي لا يحتوي إلا أمر الواجهة يعيد الاستماع بلا خطأ صوتي كاذب.
- لكل عملية نسخة إعدادات ثابتة تشمل مسار الخادم والبديل. التغيير لا يبدل القراءة الجارية أو إعداد محاولة تجهيزها في منتصف العملية؛ يُستخدم في العملية التالية.
- صححت عبارة «تُطبَّق التغييرات مباشرةً» إلى توقيت القراءة التالية، مع توضيح أن صوت الجهاز المتاح قد يختلف عن صوت الخادم المختار.
- إعداد preset ونوع الصوت متسقان عند تمرير إعدادات جزئية. مطابقة أسماء أصوات الجهاز محدودة بالكلمات بدل مطابقة `male` داخل `female`، دون ادعاء وجود بيانات معيارية عن النوع في Web Speech.

## إصلاح منصة التحقق نفسها

كشفت المعاينة البصرية أن مشغّل اختبارات SONIM كان يحمل CSS الرئيسي، لكنه لا يحمل CSS المكوّنات الذي يفصله esbuild عن JavaScript. أصبح يحمل `sonim-actions.css`، مثل تحميل التطبيق لتنسيق المكوّنات المنفصلة. أضيف تحقق من `display:flex/grid` لمنع نجاح اختبار الشكل مع واجهة غير منسقة.

أُعيد تشغيل اختبارات الإجراءات والسجل والوسائط بعد هذا التصحيح. كما عدلت محاكاة الأحداث المتأخرة لتحتفظ بنسخة الاستدعاء قبل الإلغاء، بدل استدعاء خاصية تم تحريرها عمدًا. لم يُحذف اختبار منع الاستدعاءات القديمة.

التقاط صور الاختيار ينتظر استقرار لون النص الموروث، لا تغيير `aria-pressed` فقط؛ يمنع تسجيل لقطة انتقالية يبدو فيها الرقم داكنًا فوق زر داكن.

## الحدود الباقية

- لم تُختبر أصوات مزود حقيقي أو سماعات فعلية أو Safari/iOS أو WebView Android في هذه الدفعة. أحداث المحرك تؤكد حالة برمجية، لا أن المستخدم سمع الصوت فعليًا أو أن مستوى صوت النظام مسموع.
- إبطال الانتظار لا يوقف بالضرورة عمل فك الترميز الأصلي أو معالجة الخادم وفوترته؛ يمنع استعمال النتيجة القديمة فقط. تحرير النتائج المتأخرة أفضل جهد بحسب واجهة المتصفح.
- مهلة القراءة المحلية تقديرية، وتتأثر بطول النص والسرعة والمحرك وتعليق الجهاز؛ ليست ضمانًا لمدة النطق أو دقته. لا يُعرض انتهاء المهلة كاكتمال ناجح.
- التعرف على نوع الصوت المحلي من اسمه اجتهادي؛ بعض الأجهزة لا توفر الصوت أو اللغة المطلوبة. لا ضمان تطابق Aoede/Kore/Puck/Fenrir مع صوت الجهاز البديل.
- `speechSynthesis.cancel()` عملية عامة لطابور المتصفح. لا تتضمن هذه الدفعة مديرًا عالميًا لكل صوت قد تضيفه وحدات أخرى مستقبلًا.
- استمرار التسجيل والاستماع والتبديل بين أجهزة الصوت وحالات أذونات النظام ما تزال مجالات مراجعة مستقلة. لا تعني هذه الدفعة اكتمال تدقيق الصوت أو أمن الموقع كله.
