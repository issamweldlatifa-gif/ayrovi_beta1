# AYROVI — مراجعة تعميم الأيقونات والوظائف

> تقرير سابق؛ متابعة رموز الميزات والنصوص والأمان في [التقرير الحالي](FEATURES_CONTENT_REVIEW_AR.md).

**التاريخ: 20 سبتمبر 2026 · تقرير تحقق محلي، وليس إثبات نشر إنتاجي**

## ما تغير

### عائلة واحدة للأيقونات
- أُلغيت العائلة القديمة وشرط اختيارها حسب الشاشة. Navigation وHome وUser والقائمة والحساب والإدارة تستخدم المرسّم التحريري نفسه.
- **94 مفهومًا / 97 اسمًا متوافقًا**؛ Play وGrip امتدادان للهندسة المختارة، لا اتجاه تصميم جديد.
- هندسة ثابتة: شبكة 24، سماكة 1.3، نهايات square واتصالات miter. تتغير الأحجام والألوان والحالة الدلالية، لا تعريف الرسم.
- بقي شعار AYROVI وترتيب شريط التنقّل ووظائفه. أزيل عزل خط/ألوان التنقّل القديم؛ المحافظة على التنقّل لا تستثني أيقوناته.
- شعارات الجهات الأصلية محفوظة. صورة التحويل البنكي العامة ليست شعار جهة، واستُبدلت برمز التحويل من العائلة المعتمدة.
- فحص المصدر يشمل **185 ملفًا**، مع **5 جذور SVG مسجّلة**: المرسّم، علامة AYROVI المتحركة، طبقتا بيانات Lens، ومخطط مستوى الصوت. لا استثناء لأيقونات UI قديمة.

### إصلاحات وظيفية لا تجميل فقط
- **Lens:** إنهاء السحب يعتمد على الارتفاع الأخير، لا قيمة قديمة في closure. أزرار الرأس لا تبدأ سحبًا؛ مستمعو النافذة يُزالون عند الإغلاق. بقيت نقاط المسح ومقبضه دوائر وظيفية.
- **الصوت:** إعدادات موحّدة، قيم سرعة محدودة ومنتهية، نسخ آمنة للإعدادات، استجابة للمستوى الحقيقي للصوت، تقليل حركة، وحدود تركيز/Escape مستقلة لنافذة الإعدادات.
- **المنتجات:** لا تحويل لنسبة المطابقة إلى نجوم. لا يظهر تقييم إلا إذا كان تقييم تاجر صريحًا وصالحًا. الكمية عدد صحيح؛ الروابط والأسعار تُفحص؛ تعذر تحميل شروط العربون يمنع الطلب بدل اختراع نسبة.
- **السلة والدفع:** سياسة مشتركة تتحقق من النسب الواردة من الخادم. تحميل/فشل/إعادة محاولة واضحة؛ لا افتراض 20% أو خصم 5% من العميل. إنشاء طلب غير مدفوع ما زال متاحًا إذا أكدت السياسة الصحيحة عدم ضبط وسيلة دفع؛ فشل جلب السياسة لا يُعامل كغياب وسيلة الدفع.
- **السلة على الهاتف:** شروط العربون قابلة للتوسيع، لتبقى المنتجات وأزرار الكمية أقرب للعرض. تُعرض الشروط التي نشرها الخادم كما هي، مع رابط شروط البيع، لا وعد استرجاع افتراضي أو ترجمة قانونية مختلقة.
- **التعليقات:** قراءة فاشلة ليست قائمة فارغة؛ كتابة فاشلة ليست تعليقًا منشورًا محليًا. المسودة تبقى عند فشل التأكيد، ولا يتكرر الإرسال المتزامن أو ينتقل رد متأخر إلى منشور آخر.
- **الإعجابات والمشاركة:** أُزيل fallback الأعداد المحلية المصطنعة. الحالة والعدد يأتيان من تأكيد الخادم. لا يُسجّل إلغاء المشاركة كتفاعل مكتمل؛ غياب الحافظة لا يرمي خطأ غير معالج. نسخ الرابط يستخدم رابط المنشور نفسه.
- **التركيز:** كشف المتصفح أن تعطيل زر النشر قد يعيد التركيز إلى body ويعطل Escape. جرت استعادة التركيز داخل ورقة التعليقات دون سحبه من نافذة أخرى، ثم أعيد الاختبار.

## نتائج التحقق

| الفحص | النتيجة | ما يثبته |
|---|---:|---|
| الجرد وحارس الأيقونات | 185 ملفًا، صفر مخالفات | التزام المصادر المفحوصة بعقد الأيقونات |
| الجرد التفصيلي | 136 ملف عميل/مشترك، 406 مواضع تحكم | جرد المصدر؛ يشمل summary، لا كل حالات DOM |
| TypeScript وبناء الإنتاج | نجاح | بناء العميل والخادم وصحة الأنواع |
| مجموعة الاختبارات | **1112 / 1112، عبر 74 ملفًا** | عقود الوحدة/التكامل وDOM وAPI ضمن بيئة الاختبار |
| اللوحة المرجعية | **41 / 41** | الرسوم والخطوط واللغة/RTL والتخطيط المرجعي |
| واجهات العميل الفعلية | **235 / 235** | تنقّل مجهول الهوية وتخطيط الواجهات محليًا |
| الحساب الفعلي محليًا | **134 / 134** | متصفح + API + SQLite معزولة، بما فيها Firefox |
| الحالات الموسّعة | **1186 / 1186** | الصوت والمنتجات والأيقونات والتعليقات والسلة والدفع |

**المجموع 1596 تحققًا متصفحيًا، وليس 1596 عملية شراء أو اختبار مزود حقيقي.** محاكيات الحالات موسومة وتعيش في `verify/` فقط، وليست مداخل في التطبيق الإنتاجي.

- حالات الصوت: AR/FR، عروض 320/390/768، ارتفاعات 480/844، فاتح/داكن، حالات تشغيل/استماع/تفريغ/تفكير/تحدث/خطأ وإعدادات ولوحة مفاتيح.
- التجارة والتعليقات: AR/FR على 320 و390، فشل القراءة/الكتابة/الإعدادات وإعادة المحاولة وتجاوز الزر المعطّل برمجيًا.
- أعلى مساحة برتقالية في **العينة المقاسة لواجهات العميل** نحو **1.403%**؛ وفي عينة الصوت نحو **0.0163%**. هذه ليست شهادة لكل شاشة أو كل محتوى CMS مستقبلي.
- تشغيل خمس مجموعات ثقيلة معًا انتهى بمهلات وإغلاق متصفحات ولم يُحتسب نجاحًا. أُعيدت الاختبارات ومجموعتا العميل والحساب تسلسليًا فنجحت دون حذف تأكيدات أو إطالة مهلات الاختبارات الداخلية. ظهر أيضًا انتهاء مهلة تحميل Firefox مرةً أثناء تشغيل تسلسلي. أُضيف تشخيص للطلبات المعلّقة وحالة المستند عند تكراره؛ نجحت أربع إعادات متتالية بعد إضافة التشخيص دون تخفيف التأكيدات. السبب الجذري لهذه المهلة المتقطعة لم يُثبت، ولا تُوصف بأنها إصلاح تطبيقي منجز. CI ينفّذ المراحل تسلسليًا.

- حراس المصدر واختبارات الانحدار في `tests/editorial-*` و`tests/icon-architecture-guard.test.ts` و`tests/social.test.ts`.

## قواعد استمرار الاتساق
1. استخدم `QatafoIcons` أو `EditorialIcon`، لا رسومات/مكتبات UI مستقلة. إضافة مفهوم جديد تتطلب تعريفه مركزيًا واختباره.
2. عدّل مصادر الهوية، ثم ولّد الملفات. لا تعدّل CSS المولد أو اللوحة يدويًا.
3. بعد تعديل الواجهة: `design:inventory` ثم `design:check`، typecheck، build، test، ثم مجموعات المتصفح بالتتابع.
4. CI يبني SPA قبل اختبارات HTTP، يشغّل Chromium وFirefox، ويمسح أدلة المتصفح القديمة قبل توليد الجديدة. يمكن رفع أدلة مرحلة فاشلة دون نسب نتائج قديمة إليها.
5. راجع أي تغيير للحارس أو الاستثناءات؛ لا يوجد منع مطلق إذا حُذفت الحماية نفسها. إعداد branch protection البعيد لم يُتحقق منه هنا.
