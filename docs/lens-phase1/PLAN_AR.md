# Lens — المرحلة الأولى: الكاميرا والمداخل والمساعدة

## النطاق المعتمد
- الكاميرا تعمل؛ لا إعادة بناء لمحرك التصوير ولا تصميم لشاشات ما بعد التحليل في هذه المرحلة.
- العنوان بنفس الاسم الحالي AYROVIX مع معالجة طباعية من الهوية A؛ عائلة الأيقونات الحالية فقط.
- Photo / Scan en direct، ومسار واضح «رابط أو رمز» بخيارَي المسح ولصق الرابط.
- دليل ثنائي اللغة، أبيض وأسود: الوظائف والاستخدام المسموح والخصوصية، وإقرار أول استخدام 18+ والشروط قبل فتح الكاميرا من Launcher.
- الإقرار ذاتي محفوظ للجلسة، ليس تحقق هوية أو حماية خادم. منع المحتوى الإباحي/الجنسي وتصوير الوجوه والروابط المحظورة شروط استخدام؛ لا ادعاء بوجود كشف شامل أو ملاحقة قانونية تلقائية.
- المكتبة الرسمية توفر Info للمساعدة، ولا نضيف أي رسم خارجي لعلامة استفهام.

## التنفيذ والاختبار
1. تثبيت خط أساس Git المطابق للهوية المرفوعة، دون تغيير ملفات أخرى.
2. مكوّن مساعدة/إقرار مشترك وتحديث هيكل الكاميرا، وتخطيط يستجيب للهواتف وRTL والنص الكبير.
3. حماية التنقل والتركيز: الرجوع يغلق اللوحة أولًا، Escape، حجز التركيز وإعادته، تعطيل الخلفية؛ لا طلب تحليل أثناء لوحات المساعدة أو الروابط.
4. إصلاح تأخر الالتقاط الاصطناعي، وتنظيف العمل المؤجل بعد الإغلاق، وعدم إعادة طلب إذن الكاميرا عند التنقل الداخلي.
5. اختبارات وحدات فعلية ومراجعة توقعات الشكل القديمة فقط، اختبارات متصفح باستخدام كاميرا اصطناعية دون خدمات تحليل حقيقية، ثم build/typecheck/identity/icon/full tests.
6. تسليم الأدلة والحدود. لا وعد بتحسن زمن التعرف على منتجات حقيقية دون قياس على الجهاز والخدمة؛ هذه المرحلة تصقل المدخل ولا تعيد ضبط محرك التعرف.

لا دفع أو نشر تلقائي لهذه المرحلة قبل عرض النتيجة ومراجعتها. لا تغيير للشعار أو التسعير أو ملفات نتائج Lens.

## النتيجة المنفّذة
- اكتمل نطاق المرحلة الأولى، بما في ذلك التنقل الداخلي عبر سجل التطبيق، التركيز وEscape، وفصل الرابط/المسح وإقرار أول استخدام.
- نجاح TypeScript والبناء وحراسة التصميم والخطوط والأيقونات.
- المجموعة الكاملة: **89 ملفًا / 1396 اختبارًا ناجحًا** بعد المتابعة. تتضمن 20 اختبارًا لسلوك المدخل و15 اختبارًا لمحرك Live وجدولته وإلغاء جلساته.
- **135 فحص متصفح** جديدًا على Chromium/Firefox، العربية/الفرنسية ومقاسات متعددة؛ **235** فحص عميل و**401** فحص اختيار منتجات نجحت بعد الإقرار الجديد.
- عائلة الخط المستخدمة فعليًا لعنوان الكاميرا: Zalando Sans محلي وفق CDP. لا مكتبات خط أو أيقونة إضافية.
- تدقيق npm: صفر ثغرات معروفة. لم تُضف اعتمادية جديدة.
- المعاينة REVIEW.html تتضمن لقطات المكوّن الحقيقي فوق كاميرا محاكاة؛ لا تزعم اختبار هاتف/فلاش حقيقي أو سرعة محرك التعرف.
- لا تعديلات على InteractiveLensResults أو محرك التسعير أو واجهات API/QR الأساسية. أضيفت إصلاحات دورة حياة وجدولة وإلغاء في LiveVisionRuntime دون تغيير نماذج التعرف أو ترتيب النتائج؛ موثقة في FOLLOWUP_AR.md. شاشات النتائج مؤجلة وفق طلب المستخدم.
- أُغلقت بوابات القبول المحلية. يظل شرط العمر إقرارًا ذاتيًا وليس تفويض API أو تحقق هوية. نتيجة الدفع وفحوص GitHub تُوثّق في رسالة التسليم وسجل المستودع.

## متابعة الإيقاف والاستئناف
أُعيد إنتاج عيوب حقيقية في الوعود المتأخرة والإلغاء والمشهد الثابت والفلاش، وأُصلحت مع اختبارات انحدار. تفاصيل ما قبل/بعد والقيود في FOLLOWUP_AR.md. لا دفع أو نشر.

## إقفال التسليم
بعد عرض المعاينة والفحوص، طلب المستخدم مواصلة الرفع والمتابعة. يتضمن التحديث المرحلة الأولى فقط، دون مختبرات المقارنة الخاصة أو إعادة تصميم شاشات النتائج. يُدفع دون force push، وتُتابع CI منفصلة عن النشر الإنتاجي. آخر إعادة كاملة: 89 ملفًا / 1396 اختبارًا ناجحًا. إعادة تجهيز متصفحات إضافية توقفت قبل بدء الفحوص؛ السجلات المكتملة السابقة (135 + 235 + 401) محفوظة، ويعيد GitHub تشغيل مجموعاته من الصفر.
