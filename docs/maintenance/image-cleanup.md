# تنظيف الصور غير اللازمة

## النتيجة

- جرد **1566 صورة متتبعة** في Git.
- حذف **181 صورة تاريخية غير مرتبطة بمراجع الملفات المفحوصة**، بعد مراجعة مجموعاتها يدويًا.
- الحجم المحذوف: **55,586,084 بايت = 53.01MiB** (نحو 55.6MB بالنظام العشري).
- المتبقي: **1385 صورة**. لا تعني كثرة الصور أنها جميعًا تُحمّل في التطبيق؛ كثير منها مراجع أو مدخلات بناء أو توثيق.

| المجموعة | المحذوف | الحجم التقريبي MiB |
|---|---:|---:|
| معاينات design القديمة | 8 | 19.90 |
| لقطات مختبر AYWEBs القديمة | 16 | 15.89 |
| screenshots غير المشار إليها | 90 | 3.26 |
| مخرجات PNG قديمة في verify | 38 | 8.94 |
| معاينات تصميم قديمة في docs/design، دون assets المصدر | 29 | 5.03 |

القائمة الدقيقة، الأحجام وSHA-256 لكل ملف في [image-cleanup-manifest.json](image-cleanup-manifest.json). يمكن استعادة أي ملف من تاريخ Git السابق؛ الحذف لا يعيد كتابة التاريخ ولا يُنقص حجم مستنسخ Git قديم تلقائيًا.

## ما تم الحفاظ عليه

- جميع صور runtime داخل `client/public` و`apps/mobile/assets` و`assets/media`.
- أصول الهوية الرسمية والملفات المصدرية داخل `assets/brand`، بما فيها ملفات ليست مطلوبة للعرض لكنها مصادر أو مراجع اعتماد.
- صور المنتجات والمنشورات والقصص والمراجع المستخدمة في الإدارة.
- fixtures التي تُقرأ ديناميكيًا، وموارد Android التي تُحل عبر أسماء resources، وليس فقط عبر اسم الملف الكامل.
- صور التوثيق المشار إليها مباشرة، أو كمجلد دليل مثل `docs/site-structure`.
- نسخ navigation القديمة اللازمة للتوافق مع صفحات أو حزم سابقة مخزنة لدى المتصفح.
- جميع بيانات CMS والمرفقات والملفات الخاصة وقاعدة البيانات؛ لم تُحذف أو تُعدّل.

لا يثبت غياب اسم ملف حرفي في الكود أنه غير مستعمل. تمت قراءة القيم النصية في قاعدة البيانات **المحلية فقط وبوضع read-only**. لا توجد إمكانية لفحص قاعدة CMS المنشورة من هذه البيئة، ولذلك لم تُحذف صورها المحتملة بالتخمين.

## منع تراكم مخرجات التجارب

أضيفت أنماط ignore لمخرجات screenshots وPNG في verify ومعاينات design وصور مختبر AYWEBs. الملفات المرجعية التي ما زالت متتبعة تظل متتبعة؛ fixtures وموارد التطبيق لم تُضف إلى التجاهل.

أضيف أمر جرد محافظ، لا يحذف شيئًا:

```bash
node scripts/audit-image-usage.mjs
```

ينشئ `.cache/image-cleanup/inventory.json` مع مواقع المراجع، ويطبع قائمة للمراجعة اليدوية فقط. يفحص ملفات النص المتتبعة حتى 12MB، بما فيها SVG، ويُبقي الملفات ذات الاسم المشترك بشكل محافظ. الاستخدام الديناميكي وبيانات الإنتاج يتطلبان مراجعة إضافية، لا حذفًا آليًا.

## التحقق

- TypeScript للويب والخادم: نجح.
- بناء الويب والخادم: نجح.
- فحوص التصميم والأيقونات والهوية: نجحت.
- اختبارات الهاتف: **117 ملفًا، 1151 اختبارًا ناجحًا**.
- اختبارات الويب والخادم المركزة على الصور والهوية والشعارات والمنشورات والقصص: **10 ملفات، 146 اختبارًا ناجحًا**.
- فُحصت مراجع SVG للصور المحذوفة ولم يوجد اعتماد عليها.
- لم تُعد مجموعة اختبارات الجذر كاملة في هذه الجولة؛ إخفاقاتها السابقة موثقة في تقرير المراجعة وليست مُعلنة كإصلاح هنا.

هذا تنظيف للمستودع ومخرجات التجارب، **وليس قياسًا لتحسن زمن تحميل التطبيق أو حجم APK**؛ الصور التاريخية المحذوفة لم تكن ضمن أصول التطبيق المستخدمة. لم يُغيّر Stripe أو حجم القرص أو منطق الصور في الإنتاج.
