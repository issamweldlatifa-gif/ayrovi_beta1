# قاعدة عرض وسائط المنشورات: بعرض الشاشة

## طلب المالك
صور المنشورات في واجهتها لازم تكون بعرض الشاشة:
- الكروت ذات الحواف المستديرة (radius 16) → **تقريبًا بعرض الشاشة**.
- الصور ذات الحافة الحادة (بلا radius) → **بعرض الشاشة الكامل** edge-to-edge.

## التنفيذ (`PublicationCard.tsx`)
- تصنيف الوسائط حسب الشكل لا القالب:
  - **بلاطات حادة** = شبكات اجتماعية (`social_pair` / `social_strip` / `social_mosaic`) + شبكة الـ collection متعددة الصور: الهوامش الأفقية السالبة (`-mediaInset`) تلغي بالضبط gouttière قائمة الفيد (8dp) → العرض النهائي = عرض الشاشة تمامًا، مثل شبكات إنستغرام edge-to-edge.
  - **إطار مستدير** = بقية القوالب (photo, video, carousel, campaign, caption_photo, shoppable, split): يمتد الـ media بكل عرض الكارت أي الشاشة ناقص gouttière خفيفة من كل جهة — «تقريبًا بعرض الشاشة» — بدون الحذف الابتدائي 52dp السابق.
- أزرار التفاعل (الإعجاب/التعليقات) وCTA صارت بمحاذاة حافة الكارت (بلا مسافة 52) لتنسجم مع الوسائط العريضة؛ عمود النص يبقى تحت اسم الناشر كما هو (قرار سابق غير ملغى)، والفاصل السفلي بعرض الشاشة كما هو.
- لا تغيير على `PublicationMedia` الداخلي (نسب وأشكال البلاطات كما هي) ولا على الـ Viewer الأسود ( Immersive) ولا على CRM/الموقع/قاعدة البيانات.

## التحقق
- مجموعة فيد المنشورات: 79 اختبارًا ناجحًا، منها اختبار لكل قالب يثبت الهوامش الجديدة، واختبار جديد يثبت: الشبكات الاجتماعية والـ collection بهامش `-8` (بعرض الشاشة الكامل عند gouttière=8)، والصورة المفردة بعرض الكارت مع radius 16.
- كل اختبارات الواجهة: 55 مجموعة / 339 اختبارًا ناجحًا. TypeScript و`tokens:check` ناجحان، و1196 اختبار وحدة ناجح.
- لا معاينة مثبتة على هاتف حقيقي بعد هذا التعديل؛ يلزم APK جديد.
