AYROVI Admin — Références UX pour le nouveau CRM

9 maquettes de référence triées en 4 modèles. Choisissez le modèle qui vous plaît (ou mélangez : ex. « C + éléments de A »). Le remodelage ne touchera que /admin — le site public et toutes les données restent intacts.

A · SaaS clair B · Analytics sombre C · Back-office e-commerce ⭐ D · ERP complet
Modèle A

Modèle A — SaaS clair & propre (shadcn-style)

Lumineux, aéré, cartes KPI, tableaux épurés. Le style « modern SaaS » le plus courant chez Linear/Supabase/Stripe.

Modèle B

Modèle B — Analytics sombre / dégradés

Sombre, gradients violets, charts en avant. Idéal si vous voulez un « command center » visuellement fort.

Modèle C

Modèle C — Back-office e-commerce (ops orders) ⭐

Centré sur les commandes : KPIs d'activité, tableaux filtrables, pipeline de statuts. C'est LE profil qui correspond à AYROVI.

Modèle D

Modèle D — ERP complet multi-modules

Dense, data-heavy, multi-modules (stock, achats, warehouse). Puissant mais plus lourd visuellement.

Références issues de dashboards publics (Dribbble, adminlte.io, shadcnuikit, epicpxls). Généré le 13/09/2026 — AYROVI UX audit.
